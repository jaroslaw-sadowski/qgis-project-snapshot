about=PL
    Zachowaj dane wykorzystane w analizie, zanim zmienią się w źródłowych bazach i usługach. Wtyczka tworzy kopię projektu z grupami, kolejnością i stylami warstw, zapisuje wektory z atrybutami oraz obrazy map z przezroczystością. Pomaga dokumentować stan prac nad studium wykonalności lub inwestycją liniową.
    Wskaż obszar, warstwy i szczegółowość map. Pobieranie dobiera obciążenie serwerów do wyników i zasobów CPU/RAM, uzupełnia brakujące kafelki i zapisuje raport. Przenoś cały folder archiwum; po eksporcie sprawdź go bez sieci. Data oznacza czas pobierania, nie jednoczesny stan wszystkich źródeł.
    Korzysta z proxy aktywnego QGIS, wyjątków i dostępnych zapisanych poświadczeń. Interfejs PL/EN. QGIS 3.40 z PyQt5 i GDAL co najmniej 3.7; sprawdzono Ubuntu. Wtyczka łączy się ze źródłami projektu w celu pobrania danych. Nie zastępuje oryginalnego projektu. Korzysta z QGIS i standardowej biblioteki Pythona, bez dodatkowych instalacji.
    Projekt rozwijany metodą vibe coding z pomocą AI, bezpłatny i otwartoźródłowy (GNU GPL v2). Lokalne testy QGIS i paczki nie zastępują odbioru własnych danych. Więcej informacji i ograniczenia w repozytorium GitHub.
    EN
    Preserve the data used in an analysis before the source databases and services change. The plugin creates a project copy with layer groups, order and styles, stores vector features with attributes, and saves map images with transparency. It helps document feasibility studies and linear infrastructure projects.
    Choose an area, layers and map detail. Downloads adjust server concurrency using successful results and CPU/RAM resources, repair missing tiles and produce a report. Keep the entire archive folder and check it offline after export. Dates describe acquisition times, not a simultaneous snapshot of all sources.
    Uses the active QGIS proxy configuration, exclusions and available saved credentials. Polish/English interface. Requires QGIS 3.40 with PyQt5 and GDAL 3.7 or newer; tested on Ubuntu. The plugin connects to project sources to retrieve data and does not replace the original project. Uses QGIS and standard Python libraries without additional installations.
    Developed through vibe coding with AI assistance. Free and open source (GNU GPL v2). Local QGIS and package tests do not replace validation of your own data. See the GitHub repository for details and limitations.
