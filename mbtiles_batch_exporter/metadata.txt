about=EN: Archive a QGIS project for offline use, with vector data, lossless maps, styles and a report. Automatic parallel downloads adapt to client resources and server responses; interrupted downloads can be resumed. Requires QGIS 3.40+/4.x, Python >=3.10 and GDAL >=3.7 supplied by QGIS, source access and disk space; no extra Python packages. Install the release ZIP through the QGIS Plugin Manager, then restart QGIS.
    Runs locally without analytics or uploading projects/diagnostics to the author. Requests send the required area, layer parameters and authentication to selected data services. Respect their licenses, attribution and download/reuse restrictions; the author is not liable for users' violations to the extent permitted by law. GPL-2.0-only. Developed with AI/vibe coding; tested (Bandit, secret scanning, Qt6 checks, Ruff/Flake8, proxy/error handling, integrity and crash recovery).

Wymaga QGIS 3.40+/4.x, Pythona >=3.10 i GDAL >=3.7 z QGIS, dostępu do źródeł i miejsca na dysku; bez dodatkowych pakietów. Zainstaluj ZIP przez Menedżer wtyczek i uruchom QGIS ponownie.
